# ApolloCraft Essentials — atribuição

Este projeto é uma versão modificada do **uxmEssentials**, originalmente desenvolvido por UXPLIMA.

As modificações do ApolloCraft incluem identidade visual/nome público, idioma padrão em português, comando `/apollo` e um gerenciador visual de módulos. O código interno e namespaces originais foram preservados para reduzir risco de incompatibilidade.
